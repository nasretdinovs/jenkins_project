# Allure + Jenkins/Gitlab CI. Настройка автоматической отправки отчетов по почте.

## 📜 Описание проекта

Проект демонстрирует базовый процесс автоматизации API-тестирования с использованием следующих инструментов:

- **Java** и **RestAssured** – для написания и выполнения тестов.
- **Docker** и **Docker Compose** – для изолированного окружения выполнения тестов.
- **Jenkins** – для автоматического управления пайплайном тестирования и генерации отчетов.
- **GitLab CI** – альтернатива Jenkins для запуска пайплайнов.
- **Allure Report** – для наглядной визуализации результатов тестирования.

💡 **Рекомендуется:** Сделайте форк (Fork) репозитория в своём GitHub-аккаунте для дальнейшей настройки pipeline и
тестирования.

## 🚀 Основные этапы работы проекта

1. **Запуск API-тестов:**
    - Тесты используют библиотеку **RestAssured** для проверки работы тестового API Swagger Petstore.
2. **Изолированное выполнение тестов:**
    - Тесты запускаются в Docker-контейнере, чтобы обеспечить стабильность и воспроизводимость окружения.
3. **Генерация Allure-отчета:**
    - По завершении тестов автоматически создаётся Allure-отчёт.
4. **Автоматическая отправка отчёта по электронной почте:**
    - Отчет отправляется всем заинтересованным участникам проекта.
5. **Jenkins Pipeline:**
    - **Jenkinsfile** настроен для автоматического выполнения всех этапов. Он находится в директории `jenkins` проекта.
6. **GitLab CI:**
    - Также настроен .gitlab-ci.yml файл для альтернативного управления пайплайном в GitLab CI.

## 🛠️ Требования к окружению

Для работы проекта необходимо:

1. **Docker** и **Docker Compose**:
    - Проект запускается в Docker Compose для упрощения настройки окружения.
    - Установить Docker Compose можно по [официальной инструкции](https://docs.docker.com/compose/install/).
